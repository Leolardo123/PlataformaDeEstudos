## Identificação dos requisitos

Essencial é termo usado para requisitos mínimos para realização da proposta principal do sistema, e sua utilização em ambiente real.

Importante é usado em relação aos requisitos que não são absolutamente necessários, mas que sem esses, a utilização do sistema é significativamente prejudicada.

Desejável é o requisito que foi levantado, porém não precisa ser adicionado na primeira versão, mas sim como recurso adicional/diferencial em versões posteriores.

# Descrição geral do sistema

A proposta envolve um sistema para servir como plataforma de estudos unificada para os alunos de uma empresa fictícia que é o Civedit Cursos. O Objetivo é criar ferramentas que facilitem o estudo principalmente para concursos, fazendo uso de utilidades de organização, avaliação, revisão e histórico.
